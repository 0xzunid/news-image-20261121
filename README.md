News in one image — 21 November 2026 front page. Sums up 21 November's world news in a single 1024×1024 newspaper front page, drawn with Pillow: Russian missiles landing in Poland, Wall Street sliding into correction, Russia's biggest barrage of the year on Ukraine, the UK and EU sealing food, carbon and youth-mobility deals, and Erasca's ERAS-0015 pill shrinking pancreatic tumours — plus the Palisades Fire conviction, Cyclone Akvan, Voyager 1's one-light-day milestone and the US–Iran standoff in one "Also today" strip.

## Run it

```sh
python3 main.py
```

That copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The image itself is generated by `news-image-gen-20261121.py` (kept out of this repo) with Pillow and DejaVu fonts — crisp baked-in headline text, no AI-image text garbling.
